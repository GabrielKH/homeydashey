mobilefacenet.tflite: a MobileFaceNet face embedding model (112x112 RGB in, 192 numbers out),
based on "MobileFaceNets: Efficient CNNs for Accurate Real-Time Face Verification on Mobile
Devices" (Chen et al., 2018, arXiv:1804.07573).

Taken from the face_detection_tflite package (pub.dev, Apache License 2.0), whose README
states its models are Apache 2.0 licensed.
